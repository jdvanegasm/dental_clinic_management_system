## Historia Clínica
1. Cuando un Cliente se registra se inicializa un formato vacío de historia clínica en la Clínica Virtual
2. En la primera cita (Servicio/Valoración/Tratamiento) el doctor debe solicitar los datos necesarios al Cliente para registrarlos en la historia clínica.
3. El doctor y el Cliente podrán consultar/descargar la historia clínica dentro del sistema de Clínica Virtual.
4. Cada cita (Servicio/Valoración/Tratamiento) debe quedar registrada en orden cronológico y anexada a la Historia Clínica existente.
