## Tratamientos
### Caso 1 - Valoración (Caso Abierto)
1. Cliente deberá agendar una Valoración.
2. El Doctor evalúa al Cliente y diagnostica un tratamiento.
3. El sistema de Clínica Virtual inicializa un formulario de anexo a la Historia Clínica.
4. El sistema de Clínica Virtual genera el contrato con los términos estipulados por el Doctor durante la Valoración.
5. Se solicita consentimiento del Cliente para realizar la firma física y/o virtual y almacenarla (Sistema Clínica Virtual) enviando al respectiva copia del correo electrónico del cliente.
6. Se relaciona el tratamiento con el Cliente y se registra en el sistema de Clínica Virtual.
7. Según el método de pago estipulado (Pasarela de pago virtual, Efectivo, Tarjeta(Datáfono Presencial)) se realiza el pago y se registra el éxito.
8. El sistema deja en check el tratamiento para permitir el agendamiento desde el dashboard Clínica Virtual del Cliente.
