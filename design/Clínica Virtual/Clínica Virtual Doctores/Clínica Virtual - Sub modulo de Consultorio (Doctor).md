## Servicios/Valoraciones/Tratamientos(Citas)/Medicamentos/Radiografías/Piezas/ETC
### Caso 1 - Crear solicitud
1. El doctor selecciona el apartado de consultorio desde el dashboard principal, o desde el formato de modificación de historia clínica.
2. El doctor dentro del modulo selecciona el tipo de proceso que desea agendar (Servicios/Valoraciones/Tratamientos(Citas)/Medicamentos/Radiografías/ETC)
3. El doctor dentro del formulario de agendamiento, deberá seleccionar el paciente al que desea crear la solicitud de agendamiento.
4. El doctor podrá visualizar la historia clínica del paciente a partir de un redireccionamiento.
5. El doctor podrá agregar las observaciones necesarias para este nuevo agendamiento de proceso.
6. El doctor confirma la solicitud de agendamiento.
7. El sistema Clínica Virtual realiza el envío de la notificación al dashboard del paciente, junto con un mensaje via correo electrónico el cual contendrá la información de la solicitud de agendamiento. 
8. El paciente podrá agendar de forma directa esta orden de agendamiento desde su panel de notificaciones dando click en la notificación que lo redireccionará al apartado de agendamiento de citas.
9. O podrá descargar, imprimir o mostrar de forma digital el documento enviado al correo con la orden de la cita y un funcionario de servicio al cliente lo podrá ayudar a agendar.
